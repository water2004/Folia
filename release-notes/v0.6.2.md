# Folia 0.6.2

This release improves AI completion edits, streaming reliability and editor interactions.

- AI suggestions can now replace or reuse text after the cursor, including existing
  paired delimiters. A diff preview distinguishes inserted and removed text;
  acceptance uses one reversible editing transaction in rendered and source modes.
- Unify keyboard handling for TeX completion, snippet placeholders and AI suggestions.
  Local completions take priority, and reaching the final snippet stop releases Tab.
- Keep stable preceding and following context before the active editing region to
  improve prompt-prefix reuse. Context capture and proposal caches remain bounded.
- Use an inactivity timeout for streamed AI responses instead of a total request
  deadline. Read available data promptly and finish at the protocol's terminal event
  without waiting for the connection to close.
- Fix caret placement when long inline suggestions wrap across multiple lines.
- Fix nested math bracket completion before scalable closing delimiters, including
  inner braces in `\left(\right)`, using parsed delimiter ownership.
- Keep window dragging from blank title-bar areas separate from tab tear-out gestures,
  including after switching tabs and when tabs overflow.
