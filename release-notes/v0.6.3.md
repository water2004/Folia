# Folia 0.6.3

This release improves completion interactions, multi-window text input and nested math editing.

- Keep AI predictions available alongside TeX suggestions and snippet arguments.
  Tab accepts visible AI text, Ctrl+Right accepts its next word, and arrows plus
  Enter remain available for TeX candidates. Without an AI proposal, Tab returns
  to command completion or snippet navigation.
- Trigger predictions after typing over selected text, including a snippet argument.
  Preserve parameter navigation for edits within the active argument and retire
  outdated tab stops when an accepted edit crosses its boundaries.
- Keep all settings pages anchored to the left of their content area as the window
  grows, with a shared maximum reading width and bounded virtualized list viewports.
- Correct CoreText focus ownership across windows. Ignore late focus-enter requests
  from inactive windows, handle system focus removal, and restore the active editor
  after WinUI completes its focus transfer without taking focus from native text boxes.
- Preserve container indentation on every editable display-math source row in quotes,
  nested quotes, lists, task lists, callouts and footnotes. Fix empty-row caret placement,
  hit testing and source boundaries around layout-only spacing and math delimiters.
