# Folia 0.7.1

This release improves large-document editing, expands native Mermaid support,
and adds a portable Windows build.

- Load large Markdown files with progress tied to parsing and indexing. Keep
  text layouts near the viewport, compact source mappings, and preserve the
  visible reading position when text reflows.
- Use formatting and insertion commands in source view. Improve range
  formatting, list editing, and clipboard behavior across both views, and keep
  Unicode grapheme clusters intact during cursor movement and deletion.
- Render TeX in supported Mermaid labels with Folia's native MathJax engine.
  Expand diagram syntax and shape support, and improve ELK routing for feedback
  edges, self-loops, and nested subgraphs.
- Keep settings actions visible as the window resizes. Dragging empty title-bar
  space now moves the window without detaching a background tab.
- Choose the installation folder in the MSI and optionally remove Folia user
  data when uninstalling. The portable x64 ZIP runs from an extracted folder
  and keeps editable settings and themes beside `Folia.exe`.
