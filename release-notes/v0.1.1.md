# Folia 0.1.1

Folia (折笺) is a native Windows Markdown reader and editor built with WinUI 3,
Direct2D, DirectWrite, and C++23. This maintenance release continues the early
0.1 series with fixes and packaging improvements.

## Highlights

- Source-faithful rendered editing backed by a unified block tree and lossless
  block-local inline CSTs, plus a monospaced source mode with line numbers.
- Native rendering for tables, nested lists and quotes, task items, footnotes,
  callouts, safe embedded HTML presentation, SVG images, animated GIFs, and
  common Windows image codecs.
- MathJax formula rendering with standard extensions and editable previews,
  asynchronous Mermaid diagrams with live previews while editing, and
  Tree-sitter code highlighting.
- Semantic copy and paste, transactional undo and redo, regular-expression
  find and replace, configurable context-aware shortcuts and snippets, and
  ranked LaTeX command completion.
- ICU-based encoding detection, reopening with a selected encoding, and
  conversion saves that preserve the chosen document encoding.
- English and Simplified Chinese interfaces, configurable themes, outline
  navigation, Windows file association, and cancellable native PDF export.

## Installation

Download `Folia-0.1.1-x64.msi` from the assets below and run it for a per-user
installation. Folia supports 64-bit Windows 10 and Windows 11. The installer is
self-contained with the required Windows App SDK runtime.

The MSI is currently unsigned, so Windows SmartScreen may ask for confirmation
before installation. The accompanying `.sha256` asset can be used to verify the
download.
