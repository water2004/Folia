# Folia 0.5.1

This update fixes equation numbers overlapping long display formulas.

- Resolve MathJax's percentage SVG width against the formula's actual container
  and preserve its intrinsic minimum width. Equation content and its number now
  share the correct viewport, including in narrow documents.
- Apply the same handling to individual and batched formula rendering, while
  preserving MathJax's nested layout and ordinary inline formula dimensions.
- Add regression coverage for tagged equations, aligned equations, font sizes,
  container widths and the SVG normalization used by the application.

For an equation number on an `aligned` group, place `\tag{...}` after
`\end{aligned}`. MathJax does not allow `\tag` inside `aligned`.

Download `Folia-0.5.1-x64.msi` for a per-user installation or upgrade. The package
includes the Windows App SDK runtime; the accompanying `.sha256` file contains
its checksum.
