# Folia 0.3.2

This release improves in-place editing, code blocks, formula completion, and
native math rendering, and fixes a settings-control lifetime issue.

## Editing

- Complete inline formatting keeps its Markdown markers hidden while the
  toolbar shows the active bold, italic, strikethrough, and code state.
  Incomplete syntax remains visible; the original source is preserved.
- Clicking a formula no longer turns into an unintended selection when its
  source expands. Math editing and live preview remain in the document.
- Code blocks use a quieter background without the surrounding outline.
  Correct standalone block positioning restores the language selector.
- Search code languages and confirm a choice explicitly. Syntax highlighting
  distinguishes function names from arguments and preserves code colors in
  preprocessor blocks and template-string expressions.
- Formula completion uses the WinUI Acrylic background.

## Performance and memory

- Reuse live completion rows and release them when completion closes or is
  accepted. Fix a self-reference that retained shortcut dropdowns after the
  settings list was rebuilt.
- Reduce native TeX parsing overhead, temporary font-lookup allocations,
  repeated math-block ownership bookkeeping, and layout-default construction.
- Write SVG attributes directly and borrow request-owned glyph paths instead
  of making intermediate copies. The shared math-layout architecture and
  request-scoped font ownership remain unchanged.

## Verification

- Core: 752 tests and 499404 assertions passed.
- Windows editor: 82 tests and 3446 assertions passed.
- Native math: 972 tests and 536146 assertions passed.
- WinUI application: 28 tests and 557 assertions passed, including real SVG
  expansion, selection, undo, completion lifetime, and settings-control release.
- Before/after SVG comparisons were byte-identical for the measured cases.
  Local performance measurements used Debug builds; they do not establish a
  fixed whole-application speedup or a measured reduction in total GUI memory.
