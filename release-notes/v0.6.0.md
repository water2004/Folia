# Folia 0.6.0

This release adds native AI input prediction and improves settings, tabs and
code-block editing.

- Configure an independent service base URL, protocol, model and API key in
  Settings. Inline suggestions appear as muted text; Tab accepts the suggestion,
  Ctrl+Right accepts the next word, and Escape dismisses it. Acceptance uses the
  normal reversible source-edit transactions in rendered and source modes.
- Adjust context size in KB, maximum output tokens and Conservative, Balanced
  or Proactive suggestion frequency. Fetch reasoning levels from upstream model
  metadata on demand instead of using preset model options.
- Show native request progress and distinct suggestion, empty-result, output-limit
  and failure states. Context, response memory and caches stay bounded; obsolete
  requests are cancelled without blocking the editor or uploading entire files.
- Restore Settings Back navigation, unify form styling and virtualize the long
  shortcut, LaTeX and license lists. Closed setting choices no longer change
  selection with the wheel; numeric budgets use plain integer inputs.
- Fix code-fence completion and paste so typing stays in the code body instead
  of changing its language. Generated headers and padding no longer capture the
  caret, including code blocks inside quotes and lists. Undo restores exact source
  and selection.
- Coordinate tab selection and document presentation, fix selected hover states,
  and close unused hidden tear-out hosts with their source window so closing
  Folia releases the process and executable.

Download `Folia-0.6.0-x64.msi` for a per-user installation or upgrade. The package
includes the Windows App SDK runtime; the accompanying `.sha256` file contains
its checksum.
