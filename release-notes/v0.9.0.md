# Folia 0.9.0

## Agent chat

Open **Conversations** in the sidebar to start a chat or resume one. You can
keep a document and a conversation side by side, quote an open tab with `@`,
and follow a reply’s file references back to the source line.

- Replies stream into Folia’s Markdown renderer, including math and Mermaid.
  Expand an activity row to inspect a tool call or a reasoning summary returned
  by the provider.
- Choose which open documents or folder the agent can read. Web search, page
  retrieval and image input are available when the configured connection and
  model support them.
- Longer conversations load recent messages first. Scroll back for earlier
  turns, check context usage in the toolbar, or use `/compact` to summarize the
  active context. The original messages remain in the conversation.
- Configure providers and their models in **Settings → AI providers**. Chat and
  inline completion use the same catalog. Existing inline completion settings
  from 0.8.1 are imported on upgrade.

## Workspace

Split the editor into two adjustable groups, move tabs between groups or
windows, and drop files onto the group where you want them to open. Settings
also lets you choose where files opened from Explorer appear.

The selected tab and its document share a reading surface from startup. The editor keeps text aligned to device pixels at high DPI and preserves equal side margins when the scrollbar appears.

The Windows x64 MSI and portable ZIP each include a companion SHA-256 checksum.
