# Folia 0.5.0

This release adds folder workspaces and document tabs, improves formula and
code editing, and separates reusable Markdown parsing from editor behavior.

## Workspaces and navigation

- Open a folder in a compact, lazily loaded file tree, with the document outline
  in its own sidebar. The file sidebar stays hidden until a folder is opened
  or the user explicitly shows it.
- Single-click a file to preview it; double-click or start editing to keep its
  tab. Each document retains its selection, undo history, unsaved changes and
  viewport when switching tabs.
- Create files and folders, rename in place, and move or copy with drag and drop.
  File operations run asynchronously and report progress while preserving the
  state of affected open documents.
- Combine tabs and window controls in one title strip. Improve sidebar icons,
  tree indentation and guides, overflowing tab controls, folder selection,
  context-menu placement and right-click selection preservation.

## Editing and mathematics

- Show an asynchronous floating preview while editing inline math, without
  adding preview height to the document layout.
- Use shared formula bounds for inline and block previews, and consistent
  inline-code backgrounds, spacing and decorations across paragraphs and tables.
- Render code-block language headers with the document, so they scroll together.
  Choose a language from one compact searchable panel. Include the final empty
  line in a code block's background when editing at its end.
- Add the native MediaWiki TeX alias package, including `\lang` and `\rang`
  delimiter support. All 101 original definitions are accounted for; existing
  MathJax 4 definitions keep precedence. Update formula completions accordingly.

## Architecture and validation

- Provide a standalone `folia::markdown` CMake target and `import folia.markdown;`
  for the block tree, lossless inline CST, parser, serializer and document queries.
  Editing, selection history and layout remain separate responsibilities.
- Separate image resource ownership from renderer device caches, and keep the
  native math C ABI header inside its owning module.
- Consolidate test runners under `tests/` and remove obsolete migration tools,
  candidate patches and historical progress reports.
- Development validation passed 763 core tests, 84 platform tests, 111 WinUI
  tests, five encoding tests and three standalone Markdown consumer tests.
  Official CommonMark coverage passed 652 cases; the GFM suite passed 1,428
  tests. Native mathematics passed 977 tests, including package and SVG checks.
- The release workflow builds a self-contained application and verifies its
  real startup and normal closure before packaging the MSI.

## Installation

Download `Folia-0.5.0-x64.msi` below for a per-user installation or upgrade.
The package includes the Windows App SDK runtime. Its accompanying `.sha256`
file contains the MSI's SHA-256 checksum.
