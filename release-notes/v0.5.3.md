# Folia 0.5.3

This update improves math editing and adds movable document tabs.

- Drag a tab out into its own window, or move it into another Folia window.
  The document keeps its unsaved changes, undo history, selection and scroll position.
- Add incremental TeX syntax highlighting and subtle bracket matching while editing
  formulas, including incomplete expressions.
- Show math previews at their actual inline size, with natural line wrapping,
  shared formula layout and a softer shadow. Previews do not scale or scroll internally.
- Add smooth caret movement and fading blink, respecting Windows animation settings
  and stopping continuous frame requests when idle.
- Fix the document preparation overlay remaining visible after an external file change.
- Preserve source-mode line identity and selection through undo and redo, and fix
  delayed window events accessing an already closed editor.

Download `Folia-0.5.3-x64.msi` for a per-user installation or upgrade. The package
includes the Windows App SDK runtime; the accompanying `.sha256` file contains
its checksum.
