# Folia 0.4.1

This release speeds up formula preparation, improves the outline, and adds
clipboard image paste and confirmation before discarding document changes.

## Formula preparation

- Group unique formulas into bounded batches across document blocks, sharing
  font work without retaining a document-sized render queue.
- Index font records by variant and reuse the default SVG font selection and
  fallback results within each batch. Release those temporary results at the
  end of the batch, including on cancellation or failure.
- In an isolated Release preparation benchmark of a 339 KB document containing
  3,213 formulas, median math preparation decreased from 6.90 seconds to
  3.27 seconds, about 53% less time. Prepared-result counts were unchanged;
  this is not an end-to-end GUI startup or displayed-frame benchmark.
- Keep editing previews asynchronous and in memory, and document SVG reads
  asynchronous and limited to current viewport demand.

## Outline and editing

- Wrap long outline headings and synchronize the active section with the
  editor viewport, including nested and repeated headings.
- Paste clipboard images beside the Markdown document and insert relative
  image references in both editing modes. Untitled documents must be saved
  first; canceling that save leaves the document and directory unchanged.
- Confirm Save, Don't save, or Cancel before closing or replacing a document
  with unsaved changes. Canceled or failed saves keep the document open.
- Preserve exact source and selection through image-paste undo and redo.

## Verification

- Development validation passed 974 native math tests, 71 WinUI tests, and
  five SVG normalizer tests. Coverage includes batch equivalence, ownership,
  cancellation, preview and scrolling behavior, document closure, and paste.
- Canonical SVG results match the pinned Source in batches of 32 and 64;
  the complete font comparison checked 14,568,049 values with no differences.
- MSI packaging now requires the real GUI executable to construct its window,
  activate, and close normally. The local upgrade also verified installed
  file hashes and preservation of settings and custom files.

## Installation

Download `Folia-0.4.1-x64.msi` from the assets below for a per-user installation
