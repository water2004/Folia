# Folia 0.5.4

This update fixes document tab transfers and window behavior.

- Keep each window's tab controls local while transferring the original document
  session, unsaved changes, undo history, selection and scroll position.
- Fix detached tabs opening an empty document, and improve empty-tab transfers
  and repeated moves between windows.
- Prevent preparatory drag windows from appearing or taking activation when
  selecting a tab, avoiding window-border and shadow flicker.
- Align tab merge detection with the tab strip's drag bounds, exclude hidden
  windows from merge targets, and complete layout before continuing a drag.
- Fix selected-tab reordering modifying the tab collection during its own
  selection notification.

Download `Folia-0.5.4-x64.msi` for a per-user installation or upgrade. The package
includes the Windows App SDK runtime; the accompanying `.sha256` file contains
its checksum.
