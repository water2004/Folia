# Folia 0.4.0

This release adds themeable SVG Markdown markers, improves semantic editing,
and fixes scrolling cadence and formula display.

## Editing and appearance

- Complete Markdown markers appear as indivisible SVG icons when their source
  is revealed for editing, and remain hidden during normal reading. Incomplete
  input such as a lone `*` stays editable source text.
- Recognize markers from the lossless CST, preserving the original Markdown
  spelling and source offsets. Icon drawing does not determine editing behavior.
- Removing a paired formatting or formula delimiter removes both delimiters
  and preserves the content. Display math becomes ordinary text when unwrapped;
  ATX heading markers still decrease one level at a time.
- Display-math marker icons align with the TeX source and use lighter strokes
  and a flatter background.
- SVG marker resources are part of all seven built-in themes. MSI upgrades and
  repairs refresh bundled themes while preserving custom themes and settings.
  Custom theme authors should follow the schema-version-2 format in
  [the theme documentation](https://github.com/water2004/Folia/blob/v0.4.0/docs/THEMES.md).

## Scrolling and formula display

- Pace scrolling with the Windows compositor clock instead of combining it
  with an independent refresh-rate timer. Keep input responsive and retain
  timer-based pacing on systems where the compositor clock is unavailable.
- Preserve subpixel inertia progress at large document offsets so the final
  deceleration settles instead of continuing indefinitely due to rounding.
- Render parsed inline content inside incomplete formatting constructs. An
  unmatched tilde before a valid inline formula no longer hides that formula.

## Verification

- Core, Windows editor, and WinUI regression suites passed during development,
  covering source preservation, semantic deletion, undo/redo, icon hit-testing,
  theme resources, scrolling cancellation, and inertia completion.
- An isolated MSI upgrade-and-repair test verified bundled-theme replacement
  and preservation of custom files and settings.
- The scrolling fix was also confirmed through manual use of the Release
  candidate. Callback cadence measurements are not displayed-frame benchmarks.

## Installation

Download `Folia-0.4.0-x64.msi` from the assets below for a per-user installation
or upgrade. The package includes the required Windows App SDK runtime.
The accompanying `.sha256` file records the MSI's SHA-256 checksum.
