# Folia 0.3.1

This maintenance release fixes intermittent document-opening errors and improves
responsiveness when scrolling through documents with many math formulas.

## Fixes

- Restore the UI apartment after waiting for the rendering surface or retrying
  a changing file. This fixes the intermittent "interface marshalled for a
  different thread" error while opening a document.
- Yield followup drawing to the UI message loop instead of recursively drawing
  from the previous frame. Scroll frames use low-priority dispatch so ordinary
  UI work can run during sustained rendering.
- Coalesce embedded-content completion notifications and repaint requests.
- Offscreen formula layout reuses existing geometry without starting new native
  work or disk reads. Canceled work no longer requests a repaint; formulas can
  be requested again when their blocks return to the viewport.

## Verification

- Added real WinUI dispatcher/controller regression tests for opening, surface
  readiness, cancellation, UI scheduling, deferred drawing, and formula work.
- All 11 application tests pass with 52 assertions; 10 consecutive runs pass
  with 110 tests and 520 assertions in total.
- All 80 deterministic Windows editor tests pass with 3429 assertions.
- The tests check rapid viewport replacement, unchanged source and selection,
  and redraw convergence. The reported long stall on the original user document
  has not yet been reproduced end to end with title-bar dragging.
