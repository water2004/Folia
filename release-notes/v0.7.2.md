# Folia 0.7.2

Folia now gives Markdown images more room and lets you choose a Mermaid theme
independently of the app theme.

- **Images scale to the available text width.** Large images can use the full
  width by default, without the old fixed height limit. They keep their aspect
  ratio, and small images stay at their original size. Set a narrower default
  width limit under **Settings → General → Images and diagrams**.
- **Choose a Mermaid theme in the same settings section.** Pick any of the 11
  built-in themes or follow Folia's light or dark theme. A theme declared in a
  diagram takes precedence. PDF exports use the selected theme as well.
- **Mermaid rendering fixes.** Radar and XY charts now inherit missing style
  values from the default theme. Nested state diagrams alternate their group
  backgrounds at each level.
- **Native Mermaid library.** Source files are organized by diagram family and
  responsibility. The public C++ renderer exposes named presets and isolated
  theme sessions through a single entry point.
