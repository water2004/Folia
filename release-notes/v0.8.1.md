# Folia 0.8.1

Folia 0.8.1 brings rich table editing to the Markdown workspace and improves
sidebar, tab, and math behavior on Windows.

- **Rich Markdown tables.** Drag to select a range, then right-click to format
  cells or merge them. You can resize columns, sort rows, add checkboxes, and
  calculate values with column formulas. Cell selections animate as you move
  or resize them. Tables use the [gogoga-table](https://github.com/jackweigogoga/gogoga-table)
  metadata format so rich table formatting can travel with the Markdown file.
- **An inward-opening sidebar.** Files and Outline slide open inside the
  window. The editor makes room while the window keeps its size and position.
- **Stable math while resizing.** Rendered equations stay visible while you
  resize the window or toggle the sidebar.
- **Easier tab closing.** Middle-click a background tab to close it while
  keeping your current tab selected. The close button has a square hover target.

Download the Windows x64 MSI for a standard installation, or extract the
portable ZIP and run `Folia.exe`. Both downloads have a companion SHA-256
checksum.
