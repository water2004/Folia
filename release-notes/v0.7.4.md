# Folia 0.7.4

Folia makes text easier to move, improves keyboard editing, and uses less
memory on large Markdown documents.

- **Drag selected text to move it.** Select text, drag it to a new location,
  and release. This works in both the rendered editor and source mode. The
  drop caret shows where the text will land, and the mouse pointer shows
  whether you can drop there. One Undo restores the text and your original
  selection. Your clipboard stays intact.
- **Smoother selection.** The highlight follows the active end of the selection
  with the same easing as the caret, whether you select with the mouse or
  extend the range from the keyboard.
- **More consistent keyboard editing.** Word and paragraph navigation are
  available in both editor modes. Tab adapts to the current context, including
  list indentation, code indentation, and moving between table cells.
- **Reliability fixes for everyday editing.** Formatting and deletion handle
  selections across tables and fenced blocks more consistently. Inserting
  links, images, and footnotes works in more contexts. Saving and reopening
  preserves more cases involving blank list lines, mixed line endings, and
  incomplete HTML. Input method composition also handles text updates more
  reliably.
- **Lower memory use in large documents.** Folia keeps document structure and
  editor navigation data in less memory, especially when working with many
  blocks or inline formatting spans.
