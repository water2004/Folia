# Folia 0.8.0

Folia 0.8.0 redesigns the Windows workspace, adds image previews and recent
locations, and restores smooth document scrolling on high-refresh displays.

- **A redesigned workspace.** Switch between Files and Outline in one sidebar.
  Document actions, character count, encoding, and source mode are available
  below the tabs. The toolbar can hide itself until you hover over it or focus
  it with the keyboard.
- **Image previews and recent locations.** Preview images in their own tabs
  while browsing a folder. Distinct icons identify Markdown, images, and other
  files. Reopen recent files and folders from the document menu.
- **More responsive tabs and large folders.** The tab strip adapts to window
  width and supports wheel scrolling. Closing background tabs and dragging the
  window work reliably after switching tabs. The file tree loads large folders
  in pages, keeping the sidebar responsive while browsing.
- **Smoother scrolling.** Editor animations run in sync with the Windows
  rendering pass, restoring smooth scrolling and caret movement on
  high-refresh displays.
- **Independent window and reading materials.** Choose Mica, Mica Alt, acrylic,
  or a solid color for each. The selected tab, document toolbar, and editor
  share the reading material.
- **Easier settings and theme previews.** Settings open in a tab with category
  pages, a return path, and preview images for themes. Custom themes require a
  PNG preview alongside the JSON profile with the same filename stem. See the
  [theme guide](https://github.com/water2004/Folia/blob/v0.8.0/docs/THEMES.md).

Download the Windows x64 MSI for a standard installation, or extract the
portable ZIP and run `Folia.exe` from the extracted folder. Both downloads
include a companion SHA-256 checksum.
