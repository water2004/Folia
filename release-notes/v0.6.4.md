# Folia 0.6.4

This release improves AI completion setup and fixes how accepted suggestions
continue existing Markdown blocks.

- Fetch models from the configured API endpoint and choose from the results or
  enter a model ID manually. Reasoning effort can also be entered manually, and
  the picker shows options when the provider advertises them.
- Give suggestions nearby source in reading order and preserve leading line
  breaks and indentation. The default guidance favors short continuations that
  follow the syntax already in use. Prompt instructions are configurable at
  runtime.
- Fix a case where accepting a suggestion after an opening display-math fence
  left the equation as plain text and pulled the following paragraph into math.
  The editor now parses the continued block in context and records the change
  as a single undoable edit. The same fix applies to continued code fences.
