# Folia 0.7.3

Folia now supports Markdown text highlights and custom callout types, and
improves the appearance of exported math SVGs.

- **Highlight text with `==text==` or `<mark>text</mark>`.** Both forms share
  the same styling. All built-in themes provide a highlight background and an
  underline with independently configurable colors and opacity. When editing a
  highlight, each complete `==` delimiter appears as a theme icon and follows
  the same cursor and deletion behavior as bold markers.
- **Use custom callout types.** Write a header such as `> [!SUMMARY]` to create
  a callout. Folia preserves the original marker spelling, title, and body
  through edits and undo.
- **More faithful math SVGs.** Exported formulas retain colors, glyph stroke
  weights, and table rules more consistently with MathJax. Incremental Windows
  builds also refresh the math runtime used by Mermaid.
