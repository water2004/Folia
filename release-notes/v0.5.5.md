# Folia 0.5.5

This update improves formula editing and fixes UI text encoding.

- Restore formula syntax highlighting, delimiter icons and caret mapping in
  quotes, lists, task lists, callouts, footnotes and nested containers by sharing
  the complete block-math source projection.
- Add syntax-aware bracket completion in formula editing: reuse existing closing
  brackets, skip matched closers, surround selections and handle scalable
  parentheses. Deleting a matched bracket removes both delimiters and retains
  their contents, with exact undo and redo.
- Keep literal paste, snippet expansion and active IME composition separate from
  bracket typing rules. Source view retains its existing direct editing behavior.
- Compile UI source as UTF-8 so modified-tab indicators and the About-page link
  arrow display correctly on machines with different build codepages.

Download `Folia-0.5.5-x64.msi` for a per-user installation or upgrade. The package
includes the Windows App SDK runtime; the accompanying `.sha256` file contains
its checksum.
