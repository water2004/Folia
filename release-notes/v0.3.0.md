# Folia 0.3.0

Folia (折笺) is a native Windows Markdown reader and editor built with WinUI 3,
Direct2D, DirectWrite, and C++23. This release brings a native math pipeline,
broader Markdown syntax coverage, and shared undo history across editing modes.

## Highlights

- Source and rendered editing now share one reversible patch history. Switching
  modes preserves undo and redo; ordinary local edits and history replay avoid
  full-document parsing and serialization.
- Undo restores exact Markdown source, block and inline CST identities, and
  selection. Batch replacements retain untouched blocks between changed regions,
  and a failed patch rolls back as a whole.
- Improved CommonMark and GitHub Flavored Markdown recognition while preserving
  Folia's editable CST and original marker spelling, escapes, whitespace, and
  physical line endings. Added the complete pinned CommonMark and GFM corpora.
- Fixed source preservation around callout titles, frontmatter, nested containers,
  tables, links, and HTML presentation. Reference-link and frontmatter metadata
  changes participate in reversible source edits.
- Replaced the QuickJS math rendering path with native C++ TeX-to-SVG rendering.
  Formula preparation runs asynchronously with stable layout metrics; editing
  previews stay in memory, and viewport loading drops obsolete requests.
- Added native batch rendering with request-scoped font loading, and startup
  cleanup of abandoned math caches that preserves caches used by other instances.

## Verification

- 752 core tests and 80 deterministic Windows editor tests pass.
- All 652 CommonMark 0.31.2 examples match strictly and save losslessly.
- All 1426 retained GFM examples save losslessly: 1395 strict semantic matches,
  20 explicit HTML presentation exclusions, and 11 documented upstream-reference
  differences; no unresolved differences.
- Added 13 patch-history test groups covering cross-mode operations, exact
  restoration, Unicode, mixed line endings, random editing, and failed replay.

## Installation

Download `Folia-0.3.0-x64.msi` from the assets below and run it for a per-user
installation or upgrade. The package supports 64-bit Windows 10 and Windows 11
and includes the required Windows App SDK runtime.

The accompanying `.sha256` asset records the MSI's SHA-256 checksum.
